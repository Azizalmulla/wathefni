## Normal-work color driver

**Assignment type** (from role / shift label) — not employee, not random:

| Type | Soft fill | Examples |
|---|---|---|
| Guest / front-of-house | warm yellow | Front desk, Guest support |
| Operations / floor | olive | Opening, Floor, Operations |
| Night | muted blue | Night supervisor (+ Next day) |
| Event / specialty | dusty pink | Event support, Training |
| General | neutral cream | Relief / Coverage |

Exceptions **replace** the category fill: Conflict, Review, Cancelled.
