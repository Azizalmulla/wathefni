# R5H authority mapping

| Concern | Authority |
|---|---|
| Survey / version / audience freeze / invitations / anonymous batches / aggregates / complementary suppression / eNPS / action plans / audit | Frozen Wave 6 C5 `engagement_c5` |
| HTTP / HR Web / Manager aggregates / Employee App | Thin adapters (`engagement_http`, `engagement_surfaces`, dashboard + Employee App clients) |
| ER / disciplinary / employment mutation | Never from Engagement. Action plan is not an ER case |
| Payroll / performance / talent / learning | Optional composition only; Engagement works without them |
| Company / actor identity | Authenticated server context only |
| Wave 5 intelligence | Explicitly safe typed facts only; no answers / free text / employee_key |
| Assistant | Read/explain only; same anonymity + suppression; no mutations |
| Recognition / AI sentiment / universal score | Out of scope; forbidden |
