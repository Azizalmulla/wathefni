# R5G safe debt

- HR Web is the investigation/evidence authoring surface; HR Mobile remains acknowledge + scoped summary.
- Employee intake/reporting is not expanded beyond frozen C4; R5G does not invent employee transparency rules.
- C4 `er_admin` global bypass is wrapped at the surface layer with grant checks; listing never falls back to company-wide.
- Evidence retrieval returns `authorized_path` only; no live object-store browser in the product UI.
- Assistant explains permitted metadata only; it does not draft findings or outcomes.
- Manager scoped contribution is the only manager path; a later explicitly permissioned thin status view would need its own amendment.
