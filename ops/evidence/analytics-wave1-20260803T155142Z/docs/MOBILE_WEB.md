# Analytics Wave 1 mobile web note

Analytics Wave 1 uses the existing HR dashboard responsive shell only.

- Attention rows are full-width stacked action buttons
- Headlines use `sm:grid-cols-2` / `lg:grid-cols-3`
- Staging dist contains responsive grid tokens (`UI_RESPONSIVE_GRID_OK`)
- No native iOS/Android work in this wave

Suggested manual check on staging: ~390px width and desktop Analytics page.
