# R5F safe debt

- HR enrollment UI is operational (prepare / elect / waive / confirm) rather than a full policy designer; Setup remains the configuration owner.
- Employee elect defaults to `employee_only` tier; family/spouse selection is available as C3 tiers and shown as dependent coverage state, not a second dependent editor.
- Contribution amounts display configured/estimated truth only; no payslip-style deduction ledger in Benefits.
- Provider/member identifiers are recorded and status-shown; no live insurer API.
- Manager visibility remains fail-closed; a later explicitly permissioned thin status view would need its own amendment.
