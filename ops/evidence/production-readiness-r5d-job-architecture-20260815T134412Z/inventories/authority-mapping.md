# R5D authority mapping

| Product object | Canonical authority | Not |
|---|---|---|
| Job family / function / profile | `job_architecture_c1` | Recruiting Job, Talent critical role, org position |
| Grade / level | `job_architecture_c1` | Comp bands, WFP grades, Talent grades, Learning grades |
| Career edge | `job_architecture_c1` | Employee eligibility, promotion recommendation |
| Employment / position mapping | JA assignment / org-position link | Employee record, employment status, salary |
| Legacy title / grade | `ja_legacy_mapping.raw_value` | Replacement of source wording |
| Talent target role | Talent C6 critical role; optional JA ref | JA catalog row |
| Requisition / Recruiting Job | Recruiting lifecycle; optional JA ref | JA job profile |
| Salary band | out of R5D (future Comp Planning) | JA grade |
