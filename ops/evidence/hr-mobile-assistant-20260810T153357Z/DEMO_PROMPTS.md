# HR Mobile Assistant — canary demo prompts (no fake answers)

Use against **live** WATHEFNI data only. Assistant must answer from spine tools / refuse honestly — never invent employees, leave balances, or candidate facts.

## Suggested prompts (EN)

1. What can you help me with here?
2. Which modules are available to me right now?
3. Summarize open leave requests I can see (if leave is enabled for this account).
4. Explain why SMS / Telegram / Teams chat send is unavailable.
5. Open candidates (expect deep-link chip only when recruiting capability is on).
6. What attendance exceptions need attention today? (if attendance enabled)
7. Cross-module: How do leave and attendance relate for this company? (honest scope)

## Suggested prompts (AR)

1. بماذا يمكنك مساعدتي هنا؟
2. ما الوحدات المتاحة لي الآن؟
3. لخص طلبات الإجازة المفتوحة التي أستطيع رؤيتها.
4. لماذا لا يمكن إرسال SMS أو Telegram من المساعد؟

## Confirm path

Only tap **Confirm** when the spine returns an active pending confirmation token for an already-mobile-safe action. Prefer prepare + deep-link into the governed native screen.
